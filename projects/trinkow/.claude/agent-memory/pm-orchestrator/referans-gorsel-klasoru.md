Mustafa görsel referansları **`/Users/mustafa/Documents/template`** klasörüne
atıyor (WhatsApp'tan gelen ham `.jpeg` dosyaları, anlamsız adlarla).

Bu klasör repo dışında ve kalıcı değil → iş için kullanılacaksa **önce repoya
kopyalanır, anlamlı adlarla:**
`projects/trinkow/docs/design/referans-gorseller/<konu>/NN-ad.jpeg`
(ör. 2026-09-17'de kalori app referansı → `kalori-app-referans/01-streak.jpeg` …
`09-ana3.jpeg`). Alt-ajanlara repo içindeki sabit yol verilir, Documents yolu değil.

Uyarlama kuralları için bkz. [[uyarlama-sadakati]].
